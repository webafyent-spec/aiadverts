A cake is sold before anyone tastes it. Whether it's a birthday cake, a batch of cupcakes for a school fundraiser or a wedding tier, customers decide from a photo on Instagram, a Facebook post or a WhatsApp Status, and they decide fast. South Africa is full of brilliant bakers, from neighbourhood bakeries to home businesses running entirely from a kitchen and a phone, and the ones that grow are usually the ones whose bakes look as good online as they taste.

The trouble is that baking leaves almost no time for photography. The best cake you made this month was probably photographed in a hurry on the counter, under kitchen lights, ten minutes before the customer arrived to collect it.

## Why Bakeries Find Marketing So Hard

- **Every cake is a one-off.** Custom cakes leave the building the day they're finished, so there's rarely a second chance to photograph them properly.
- **Kitchens are hard to photograph in.** Mixed lighting, busy backgrounds and very little space.
- **Seasons come in waves.** Christmas cakes, Easter treats, Mother's Day, back-to-school bakes and wedding season each need their own adverts, on time.
- **Order deadlines matter.** An advert for festive orders is worthless if it goes out after you've stopped taking them.
- **Margins are tight.** Every rand spent on marketing has to come back as orders, which is why it's worth doing the maths before you spend.

(function () {
  var root = document.querySelector('[data-bk]');
  if (!root) return;
  var ranges = {};
  root.querySelectorAll('.bk-range').forEach(function (r) { ranges[r.getAttribute('data-key')] = r; });

  function rand(n) { return 'R' + Math.round(n).toString().replace(/\B(?=(\d{3})+(?!\d))/g, ','); }
  function num(n) { return Math.round(n).toString().replace(/\B(?=(\d{3})+(?!\d))/g, ','); }
  function rand2(n) { return 'R' + n.toFixed(2).replace(/\.00$/, '').replace(/\B(?=(\d{3})+(?!\d))/g, ','); }

    var aov = +ranges.aov.value;
    var margin = +ranges.margin.value;

    var budget = +ranges.budget.value;
    vals.aov.textContent = rand(aov);
    vals.margin.textContent = margin + '%';
    vals.cost.textContent = rand(cost);
    vals.budget.textContent = rand(budget);
    presets.forEach(function (p) { p.classList.toggle('is-on', +p.getAttribute('data-cost') === cost); });

    var profit = aov * margin / 100;
    var spend = cost + budget;
    var orders = spend === 0 ? 0 : Math.ceil(spend / profit);
    var perWeek = Math.ceil(orders / 4);

    big.textContent = num(orders);
    week.textContent = orders === 0
      ? 'Nothing to earn back yet.'
      : 'That’s about ' + num(perWeek) + ' extra order' + (perWeek === 1 ? '' : 's') + ' a week over a month.';

    if (orders !== lastOrders) {
      dots.textContent = '';
      var shown = Math.min(orders, MAX_DOTS);
      for (var i = 0; i < shown; i++) {
        var dot = document.createElement('i');
        dot.style.animationDelay = Math.min(i * 12, 400) + 'ms';
        dots.appendChild(dot);
      }
      if (orders > MAX_DOTS) {
        var more = document.createElement('i');
        more.className = 'bk-more';
        more.textContent = '+' + num(orders - MAX_DOTS);
        dots.appendChild(more);
      }
      lastOrders = orders;
    }

    if (orders === 0) verdict.textContent = 'Set a cost or budget to see how many orders you would need.';
    else if (perWeek <= 3) verdict.textContent = 'Very achievable. A few extra orders a week covers the whole cost.';

    else verdict.textContent = 'A stretch. Try promoting a higher-value product, lowering the promotion budget, or starting with one advert.';

## Keep It Honest

AI can make a cake look extraordinary, which is exactly why bakers need to use it carefully. The advert should show your real work, in better light, not a cake you've never made:

- **Advertise what you can deliver.** Designs, sizes, colours and decorations should match what you actually bake.
- **Be clear about custom work.** If an advert shows an example, say so, so customers know their cake will be made to order.
- **Keep prices and portions accurate.** South African adverts must be truthful under the Advertising Regulatory Board's Code, and a disappointed customer's review will cost far more than the order was worth.
